# Risposte reali di Wikipedia per i test

Risposte della MediaWiki Action API registrate il 30/09/2026 e ridotte ai campi usati dai test:

- `nearby_rome_it.json`, `nearby_lisbon_en.json`: voci vicine al centro di Roma (it.wikipedia.org) e
  di Lisbona (en.wikipedia.org), ordinate per notorietà (`gsrqiprofile=popular_inclinks_pv`);
- `article_colosseo_it.json`: voce "Colosseo" in testo semplice, accorciata a introduzione e primi
  capitoli della storia;
- `imageinfo_colosseo.json`: autore e licenza della foto principale della voce.
