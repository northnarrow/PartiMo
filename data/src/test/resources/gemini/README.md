# Risposte reali di Gemini

Registrate il 1° ottobre 2026 con le richieste che l'app costruisce per il viaggio di prova
`ViennaTrip` (Vienna, 10–14 dicembre 2026, interessi "arte e musei" e "cibo"), con il modello
`gemini-flash-lite-latest` (versione `gemini-3.5-flash-lite`):

- `plan_vienna.json`: itinerario in JSON secondo lo schema di `TravelPrompts.PLAN_SCHEMA`;
- `chat_vienna_food.json`: risposta alla domanda «Cosa devo assolutamente mangiare a Vienna?».

Cambiando i luoghi di `ViennaTrip` cambiano i codici `L1`, `E2`... citati nelle risposte: in quel caso
vanno registrate di nuovo.
